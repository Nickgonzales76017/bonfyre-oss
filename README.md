## Where development continued

The canonical Bonfÿre engineering repository is
**[Nickgonzales76017/bonfyre](https://github.com/Nickgonzales76017/bonfyre)**.
The broader Aurekai software is built from native C/Zig components, typed
contracts, data and model tooling, work/authority/evidence owners, and client
experiences that can share those mechanisms.

This repository contains **an older source and Pages integration snapshot**.
Its historical references to *48 binaries*, old performance comparisons,
installation sizes, and claims about replacing entire SaaS products describe
their original examples; they are not current benchmarks or current release
guarantees. Retained code is available to inspect, but new integrations should
start from their present owners in the canonical repository.
