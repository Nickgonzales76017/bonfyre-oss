The transcription problem

What raw Whisper output actually looks like and why it needs cleanup.

Hallucinations

Whisper invents words — especially in silence

The most common Whisper hallucinations are phrases injected into silence gaps: "Thank you for watching", "Subscribe to our channel", "This video was made possible by…" — phrases that appear verbatim in Whisper's training data but weren't in your recording. BonfyreTranscriptClean removes these with Hyperscan pattern matching at >1 GB/s throughput.

Filler density

Spoken word has 15–20% filler content that reads as noise

A spoken conversation has "um", "uh", "you know", "like", "sort of", "I mean", and false starts at roughly one per every 5–7 words in casual speech. Readable transcripts are cleaned. BonfyreTranscriptClean removes these while preserving every substantive word — including intentional "like" when used as a comparison word.

Structure

A wall of sentences is not a document

Raw Whisper output is a continuous stream of sentences with no topic breaks. BonfyreParagraph segments this stream into thematic sections and infers section headings. The output has structure — it can be published directly, referenced by section, or consumed by BonfyreBrief for structured extraction.

Binary reference

All 6 Layer 2 binaries.

BonfyreTranscribe

HCP-enhanced Whisper with BM25 corpus-adaptive prompting

Runs a Hallucination-Constrained Prediction (HCP) layer on top of Whisper large-v3. HCP adds a secondary confidence model that suppresses low-confidence token predictions — reducing hallucinations beyond what BonfyreTranscriptClean catches. Accepts the speaker segment map from BonfyreSegment and produces a speaker-attributed SRT, WebVTT subtitles, and plain-text transcript. Supports 80+ Whisper language codes. No API key. No audio leaving the machine.

Corpus-adaptive vocabulary: A custom binary vocabulary store (.bfvocab, BFVD02 format) accumulates terms across every transcription run using FNV-1a hashing and BM25 weighting (k1 = 1.2, b = 0.75). Shannon entropy H and KL-divergence convergence metrics track how stable the corpus vocabulary is. Before each whisper_full() call, the top BM25-ranked terms are injected as Whisper's initial_prompt — biasing the decoder toward your domain's vocabulary without retraining. Multi-processor decode via whisper_full_parallel(). Word-level timestamps, speaker turn detection, no-speech probability filtering, repetition penalty (θ = 1.15).

BonfyreTranscriptClean

Hyperscan (>1 GB/s) hallucination and filler filter

Intel Hyperscan simultaneous multi-pattern matching across 400+ regex patterns covering: Whisper hallucination phrases, common filler words (um, uh, you know, like-as-filler), false starts, repeated stutter patterns, and transcript artifacts from silence gaps. Operates at >1 GB/s — the entire cleanup pass on a 45-minute transcript completes in under 30 ms. Preserves intentional filler uses (e.g., "like" as comparison, "I mean" as rhetorical opener).

BonfyreParagraph

Paragraph segmentation and heading inference

Segments the clean transcript stream into thematic paragraphs using sentence embedding similarity between adjacent sentence groups. When similarity drops below a threshold, a paragraph break is inserted. Section headings are inferred from the first sentence of each new section using a local summarisation pass. The output is a structured document — headings, paragraphs, speaker labels — suitable for direct publishing or downstream brief extraction.

BonfyreTranscriptFamily

Cluster related transcripts into a searchable family

Takes a collection of transcripts and analyses them as a set: computes pairwise embedding similarity, clusters by shared entity mentions and topic overlap, and produces a family structure with named clusters. Used for interview series, lecture collections, meeting archives — any scenario where you have multiple related recordings that should be navigable as a unified corpus. The family structure becomes the navigation graph for BonfyreRender's archive output.

BonfyreClips

Short-form clip extraction from long transcripts

Identifies high-value segments in a long transcript using a salience score: novelty (not similar to prior segments), completeness (self-contained thought), and brevity (under 90 seconds of spoken content). Returns a ranked list of clip candidates with timestamps. Used by BonfyreRepurpose downstream to produce social clips, highlight reels, and excerpt packages from long-form content without manual selection.

BonfyreNarrate v3

Closed-loop verified TTS with PSOLA, SSML prosody, 6-layer fidelity scoring — the HCP for TTS

v1 forked Piper and hoped for the best. v2 added tone-aware prosody and energy envelope transfer. v3 is a full DSP verification pipeline in 2,150 lines of pure C with zero Python dependencies for verification:

  • SSML prosody generation — maps the 6-dimension BonfyreTone profile to SSML rate/pitch/volume; falls back to plain text + pause injection for engines without SSML.
  • PSOLA pitch correction — pure-C autocorrelation + overlap-add shifts pitch while preserving duration.
  • Energy envelope transfer — per-frame RMS shaping from the reference audio applied to the synthesised output.
  • Inline acoustic feature extraction — radix-2 Cooley-Tukey FFT, F0 autocorrelation, RMS, jitter, shimmer, HNR — 25 features, no subprocess, no Python.
  • 6-layer fidelity scoring — pitch, energy, temporal, spectral, stability, dynamics — geometric mean composite score.
  • Closed-loop verification — extracts fingerprint from its own WAV output inline and compares with source reference.
  • Iterative refinement — converges in ≤ 3 passes, adjusting prosody parameters each cycle to close the fidelity gap.
bonfyre-narrate text.md out/ --tone-profile tone_out/profile.json --reference audio.wav --verify --refine
bonfyre-narrate verify output.wav source.wav
BonfyreSpeechLoop

Full speech transformation: input speech → structured text → new speech

Orchestrates the complete speech-to-speech transformation pipeline: Transcribe → Clean → Paragraph → Brief → Narrate. Two modes:

  • transform — takes a raw audio file, runs the full chain, and produces a narrated audio output. --compress terminates at brief stage. --brief skips narration.
  • narrate-brief — takes an existing brief directory and synthesises a narrated audio output from it.

Sibling binary resolution from argv[0] — no PATH setup required. Writes a speechloop-manifest.json on every run with mode, step chain, and completion status.

bonfyre-speechloop transform interview.wav out/ --voice-model narrator.onnx
bonfyre-speechloop narrate-brief brief_dir/ out/ --voice-model narrator.onnx
BonfyreSegment

Idea boundary detection + segment graph from word-level timestamps

Takes Whisper JSON (with word-level timestamps) and produces a structured segment graph. Three modes: graph (segment-graph.json with typed idea-boundary nodes and flow edges between them), boundaries (boundaries.json — silence-gap detected idea breaks, configurable --silence-gap default 2.0 s), rhythm (per-segment speaking rate, pause density, syllable cadence). The segment graph is the temporal navigation structure for audio archives: you can jump to idea N, not just minute N.
